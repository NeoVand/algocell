# Extended Data v8

Nine numbered displays follow the MAIN_v7 Extended Data map. Sources below resolve from `experiments/`. Figures use the existing palette, publication typography and frozen numerical tables. Full ledgers and proofs accompany the concise displays; no simulation was run.

**Unavailable measurements:** Pointer randomization was not measured and was not an S2 arm. No corresponding observation is plotted. The standard BFF harmless-bracket variant has no archived individuality-entropy panel in the source tables; it is shown only in the detection counts. All nine ED items have archived sources.
