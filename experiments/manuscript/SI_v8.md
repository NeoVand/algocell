## Supplementary Note 1. Overlap copying fixes a conditional payload count

### Ordered overlap theorem and proof

Let a ring contain P byte addresses, with all subscripts interpreted modulo P. Fix a start s and displacement d with 0 < d < P. Starting from memory M₀, perform exactly the ordered assignments

\[
M[s+d+k]\leftarrow M[s+k],\qquad k = 0,\ldots,K-1,
\]

with no interfering write or read transformation. The byte written at assignment k has original ancestry s+(k mod d). If d divides P and K ≥ P−d, the complete final ring is the d-periodic tiling of the original interval s,…,s+d−1.

**Proof.** For k < d, no earlier write has reached source s+k: its first possible write is assignment P−d+k, which exceeds k. It therefore still contains its original byte. For k ≥ d, the most recent write to source s+k occurred at assignment k−d. Writes to that physical address are separated by P assignments; because d < P, no later congruent write precedes k. By induction the value at that source is the original byte at s+((k−d) mod d) = s+(k mod d). This proves the ancestry statement for every write, including after wrapping. If d divides P, a destination with physical offset j = d+k mod P has the same residue modulo d as k. Every write therefore supplies the original byte of its own residue class. The first P−d writes cover offsets d,…,P−1; the first d positions retain their own original values or subsequently receive copies of those same values. Later writes preserve the tiling. Thus every address has the asserted value and ancestry. ∎

For two length-L tapes, take P = 2L. When d divides L, the physical partner position q has ancestor s+((L+q−s) mod d), provided the protected root interval lies in the original parent. With s = 0 this is q mod d. Let C be the independently established constrained coordinates within a protected d-byte seed; all other seed bytes must be jointly arbitrary without changing execution, coverage, offspring viability or entry machinery. The free coordinate set is F = {0,…,d−1}\C, with r = d−|C|. Each assignment to F produces a distinct offspring because every seed coordinate occurs in the covered output. There are therefore 256^r members of this product family, or log₂(256^r) = 8r ideal noiseless bits. This is a conditional mathematical count, not a measured Shannon capacity, a claim of neutral fitness or an exhaustive intervention result. Independent validation of family membership after reset permits the same argument in every generation. [Proof specialization: `manuscript/MAIN_nature.md`, Proposition 8; generated geometry: `results/capacity/geometry_traces.csv.gz`]

### Z80 specialization of Proposition 8

This specialization uses tape length L ≤ 64, a 2L-byte encounter ring, zero initial registers and flags except the specified stack pointer, physical entry zero and a budget of 128 execution steps; each `LDIR` repetition consumes one step. The parent begins with the four bytes `XX 5e ed b0`. Set d = XX mod 2L and require 4 ≤ d ≤ L and d dividing L. The initial one-byte instruction XX must pass control to address 1, must preserve every byte below d and must leave HL ≡ 0 and 256D ≡ 0 modulo 2L, with BC either zero or at least 126. Architectural source and destination increments must preserve the specified constant displacement in the mapped ring throughout the remaining copies. This last requirement excludes an unexamined architectural wrap that changes the mapped displacement; congruence of the initial pointers alone is insufficient.

Under these conditions the whole encounter leaves both tapes equal to the d-periodic tiling of the parent’s original first d bytes. Every assignment to coordinates 4,…,d−1 is transmitted jointly and serially, and initial coordinates d,…,L−1 are overwritten before contributing ancestry to the offspring. Exactly d−4 coordinates outside the held four-byte core are consequently free.

**Proof.** The first instruction preserves the protected prefix and hands control to `LD E,(HL)` at address 1. That instruction reads the original byte XX at mapped address zero. Since 256D ≡ 0 modulo 2L, DE now maps to d, while HL maps to zero. There are 126 executions left. BC = 0 means a decrementing block operation has 65,536 iterations before exhaustion; BC ≥ 126 likewise permits all remaining iterations. With the architectural-increment requirement, iteration k reads physical k mod 2L and writes (d+k) mod 2L. The overlap theorem gives ancestry k mod d. Because d divides 2L, writes to core addresses 0,…,3 restore their own original bytes, so the still-executing block instruction is preserved. The 126 copies cover the ring because 2L−d ≤ 128−4 = 124 ≤ 126. The first instruction’s possible writes outside the prefix disappear before they are read by the moving copy. Finally d dividing L aligns B with the parent seed at physical entry zero. Free seed bytes are data, and the fixed execution certificate makes their simultaneous values irrelevant to control; descendants inherit both those bytes and the same core. Reset therefore puts each descendant in the same admissible family, proving serial inheritance by induction. Initial coordinates at or above d are overwritten from the seed before being read, establishing erasure of their original ancestry. ∎

The proof checks that admitted one-byte setup instructions under this reset do not introduce a harmful 16-bit pointer wrap during the block operation. The candidate and setting ledgers also identify the executed code and geometry. The immediate form `1e NN ed b0` has d = NN mod 2L and 127 copying executions after `LD E,n`; it has the same four held core bytes and payload formula under the corresponding hypotheses. Reverse `LDDR` does not inherit this forward proof. [Current certificates: `results/capacity/candidate_eligibility.csv`, `results/capacity/edit_eligibility.csv`; historical derivation: `manuscript/MAIN_nature.md`, Proposition 8]

The conditions are substantive. At L = 16, `0x70` (`LD (HL),B`) nominally gives d = 16 and reaches address 1, but overwrites source byte zero with zero, so `LD E,(HL)` loads zero and the claimed copy fails. Taken returns such as `RET NZ` can preserve registers while violating the entry condition and using partner-dependent stack contents. With d ≤ 3, early overlap can destroy the block instruction. If d divides 2L but not L, the ring can tile correctly while the physical offspring begins in a different phase, so serial entry and the d−4 result do not follow. If d does not divide 2L, wrapped writes can place different residue classes onto the core. If coverage is insufficient, original partner bytes can survive. The stated family excludes these cases before retention is assessed.

Holding the four core coordinates fixed does not establish that they cannot transmit alternative alleles. Some core substitutions preserve a working mechanism, including alternative offset-setting opcodes. A thresholded single-mutant site score can include such machinery alleles or lose genuine copied data under its whole-tape qualification gate; it is therefore distinct from the fixed-footprint payload count. Visible repetition of a baseline tape likewise need not equal its effective copying displacement. ## Supplementary Note 2. Provenance certifies ancestry and serial closure

### A sufficient family certificate

A certificate specifies a family of parent tapes, the held code/dependency coordinates, reset state, allowed partner inputs, instruction budget, encounter termination, physical offspring boundary and entry phase. Initially every parent and partner byte receives a distinct symbolic origin. A pure copy inherits its source’s origin at the time of the read. If the source byte was overwritten, the copy inherits the origin carried by that write. Matching numerical byte values never merge original coordinates. Register transfers preserve labels only where the semantics prove an exact byte transfer. Unknown transformations and arithmetic on values cannot be silently treated as literal copying.

For every jointly admitted payload assignment and partner, the certificate must establish that the ordered execution remains valid, every physical offspring byte has the predicted parent source, no original-partner input reaches the relevant output and the copied machinery and physical entry remain viable. It must also prove that reset places that actual offspring within the same certified family. A single baseline trace supports extraction of a candidate certificate; it cannot by itself prove noninterference for arbitrary values. An unmodelled instruction or dependency remains unresolved, rather than being inferred away from observed retention. [Certificate implementations and ledgers: `results/capacity/candidate_eligibility.csv`; `results/evolved6502/eligibility.csv`; `results/s8086/prelaunch/ASTRA_PRELAUNCH_REVIEW.md`]

**Serial certificate theorem.** Suppose every allowed parent/partner encounter in a family has the same certified offspring source map, independent of the partner’s unknown contents, and every offspring belongs to that family after reset. Then its ancestry follows successive composition of that map. To conclude preservation of free information, additionally require that the induced offspring map is injective on admitted free assignments and that its output again represents an assignment in the same certified family. The recovery rule must be common to the declared partner class; conditional invertibility requiring knowledge of an unobserved partner is insufficient.

**Proof.** The first encounter satisfies the certificate by hypothesis. Its actual offspring belongs to the same family, so the certificate applies to the second encounter with its independently allowed partner. Repeating proves the ancestry claim by induction. For information preservation, each per-encounter map is injective on the admitted family, and a finite composition of injective maps remains injective. The starting free assignment therefore remains recoverable after every finite number of generations. In the protected-seed specialization, every free root is represented in the covered descendant and the idempotent tiling map preserves its first-generation canonicalization. The proof requires continued offspring membership in the certified family, noninterference and recoverability. It does not depend on the number of sampled partners. ∎

This is a sufficient criterion for a pure-copy family. Arithmetic encodings, changing programs and more general channels may transmit information while falling outside it. Failure to certify them is not proof that they lack heredity.

### Shifted source roots in amended S2 L2

The sampled baseline is d-periodic at physical entry zero, with d dividing L. Ordered writes have geometry s+k→s+d+k modulo 2L. The original root interval R = {s,…,s+d−1} must lie within A; full B coverage, no original-partner read and no interfering write are required. For each physical offspring position q, the predicted source is

\[
a(q) = s+((L+q-s)\bmod d).
\]

The raw held footprint K is extracted before retention. Its bound c = 1+max(K) ≤ d is retained, but the exact constrained root set is C_R = {a(k):k∈K}. Free roots are F = R\C_R; erased coordinates are E = A\R. The exact count is d−|C_R|, which need not equal d−c. Both K and C_R are held. Mutable erasures are E\K; held-erased coordinates E∩K can govern setup even though their original ancestry disappears. Dependencies must not be reduced modulo d to conceal a physical setup requirement. All comparisons use B’s physical coordinates, without a favourable rotation. [Prospective amendment: `REVISION_PREREG.md`, S2 B2; certificate review: `results/s8086/prelaunch/ASTRA_PRELAUNCH_REVIEW.md`]

The baseline periodicity makes A[k] = A[a(k)] for each held coordinate. With K and C_R fixed and the complete execution certificate intact, copying reconstructs every held byte at physical entry. Each free root’s assignment is reproduced at its predicted output coordinates. As d divides L, a(a(q)) = a(q), so the map composes with itself. These facts establish the serial family condition; copying values that happen to match the core in one trace would not establish it.

### Inflow and confinement are different properties

Fix the parent’s tape X = x and draw a partner E from the declared distribution. Let Y be the full physical partner tape after execution. With deterministic execution conditional on x and E, the information inflow is I(E;Y|X = x) = H(Y|X = x). Perfect copying, P(Y = x|X = x) = 1, implies H(Y|X = x) = 0 and hence zero inflow. The converse fails: a regenerator can produce the same canonical output for every partner while erasing an introduced parental change. These two statements distinguish zero inflow from faithful inheritance. If execution has additional randomness, entropy alone also includes that randomness and cannot be identified with partner mutual information without the corresponding conditioning.

The empirical estimate is plug-in offspring entropy over 256 partners. Its sample ceiling is log₂256 = 8 bits; a ceiling value does not establish an eight-bit bound on the true output diversity, and zero over the sample is sampled independence. Confinement does not guarantee zero inflow because unwritten offspring bytes can retain partner contents. Zero inflow does not require confinement if all accessed partner contents have first been overwritten independently of their originals. The BFF literal-bandwidth controls supply this dissociation. ## Supplementary Note 3. Literal-channel results have restricted scope

### Copy cost and repeated instruction addresses

In unmodified BFF, a pair has 128 byte positions; the instruction pointer and both data heads start at zero, and each head movement changes its position by one byte. An arithmetic or copying instruction changes at most one byte and does not also move a head. To make B an exact copy at a fixed shift when every original B byte differs from the desired copy requires at least 64 changing instructions. The heads must collectively visit all 64 B byte positions; from their shared initial position zero, v moves can expose at most v new positions, so at least 64 head moves are also required. The sets of operations are disjoint, giving at least 128 instruction executions. If all executions stay within A’s 64 addresses, some address is revisited. Without a bracket transfer the instruction pointer advances; the return requires a taken backward bracket jump. This is a repeated address, not a periodic full machine state. [Original statement and proof: `manuscript/MAIN_nature.md`, Theorem 1]

More generally, an execution confined to L instruction-start addresses repeats an address whenever it completes a copy costing more than L executions, or it cannot terminate inside A before a budget T > L is spent. Otherwise at most L distinct starts could execute, contradicting the premise. In the historical benign Z80 harness a held `HALT` counts as repeated residence at its own address; this convention establishes repetition, not a dynamically traversed loop. Lethal zero-opcode stopping and budgets at or below L invalidate the budget premise. The BFF copy-cost argument does not rule out a straight pass over all 128 pair addresses. Earlier proposed uniform-partner and zero-partner straight-line bounds were withdrawn because partner-dependent tests and writes ahead of the instruction pointer invalidate their proofs. [Scope corrections: `manuscript/MAIN_nature.md`, Theorems 1–2]

A self-consistent literal-write instruction or macro can construct a straight-line self-writer when its prescribed stream is executed and its writes cover the partner with the correct phase and budget. Default instruction flow makes such a program open only if execution actually reaches the partner before stopping. A different conditional statement says that if any execution visiting each instruction address at most once cannot complete a copy in the specified context, every self-writer repeats an address. The historical default-flow application also assumes execution ends upon leaving the pair. That copy-cost premise is not established for BFF by the preceding bound, and the exit premise fails for the ring Z80. These constructions do not prove which replicator evolves first. [Corrected reading: `manuscript/MAIN_nature.md`, Theorem 6; `results/literal_channel/CHECK.md`]

### Repeated load–push pair theorem

Let a load opcode a consume w following literal bytes L, setting one data register R verbatim. Let the distinct one-byte push opcode b emit a fixed permutation π(L), preserve R and move a separate stack pointer by −w. Assume the executed stream remains E = (a L b)^∞, consecutive pushes occupy contiguous w-byte blocks and the final compared region consists of those writes without holes, unrelated writes or source-stream modification. For a finite copied window of N bytes require

\[
N\ge (w+2)+w-\gcd(w+2,w) = 2w+2-\gcd(2,w).
\]

Under these hypotheses, odd w cannot produce an exact copied window. Even w admits precisely the compatible alternating layouts: E = (a b)^∞, L = (b a)^(w/2) and π(L) also alternates. For an infinite exact stream the conclusion needs no finite-window bound.

**Proof.** Each push emits the same block C = π(L). Reading the descending stack in ascending address order reverses the order of successive blocks, not the internal layout of each block, so the output is C^∞ up to phase. A matching N-byte window has periods w+2 and w. The Fine–Wilf period lemma at the stated length gives period g = gcd(w+2,w) = gcd(2,w). The window covers a complete execution period, so the g-periodicity extends to E. For odd w, g = 1 forces a = b, contradicting distinct opcodes. For even w, g = 2 forces alternation; byte zero is a and byte w+1 is b, giving the stated L. The output permutation must preserve alternation. Conversely any such permutation writes a shift of E, proving the stream construction. Actual encounter bootstrap and coverage remain additional conditions. ∎

The finite bound is 2w+1 for odd widths and 2w for even widths. The shorter odd-width bound 2w is insufficient: w = 1 permits execution period `a a b` and a two-byte output `a a` before disagreement. At w = 3, execution `a b a a b`, literal `b a a` and permutation (1,0,2) emit block `a b a`; the six-byte window `a b a a b a` matches before disagreement. These are explicit counterexamples to the shorter finite bound. An independent symbolic equality check covers all 46,233 layouts for widths 1,…,8. For w = 2r there are 2(r!)² compatible layouts; both width-two permutations work. [Generated records: `results/literal_channel/pair_layouts.csv`, `results/literal_channel/finite_bound_counterexamples.json`, `results/literal_channel/verification.csv`]

The theorem characterizes a restricted literal channel, independently of the default-flow/copy-cost results. Loads to the stack pointer are excluded: their value changes addressing, and the original-8086 `PUSH SP` stores the decremented pointer. Transient pushes using initial register contents cannot be silently substituted for the recurrent load–push stream. The Z80 words `01 c5`, `11 d5` and `21 e5` are width-two immediate-load witnesses. The other two nontrivial period-two census words, `2a e5` and `e5 2a`, use a memory load and are outside this literal grammar. Thus three, not five, of the five nontrivial words are literal-channel witnesses. The validated census and causal classification define the 8086 inventory used here (Supplementary Note 8). [Generated Z80 agreement: `results/literal_channel/census_audit.csv`, `results/literal_channel/census_provenance.json`; current 8086 census: `results/census8086/table_main.csv`, `results/census8086/table_hits.csv`]

### Width-one mixtures cannot write the same infinite periodic stream

Allow arbitrary finite sets of distinct load and push opcodes, with disjoint opcode sets. Every load consumes one literal byte and sets the same one-byte register; every push emits that register unchanged and advances the separate descending pointer by one. Decode a prescribed periodic input sequentially. Exclude the degenerate constant all-push writer supplied with an initial register already equal to its push opcode. There is no nondegenerate infinite periodic self-writer in this model.

**Proof.** Let d be the input’s primitive byte period. At a token boundary, opcode identity determines whether the next boundary is one or two bytes later, independently of R. The finite graph of boundary residues modulo d therefore eventually enters a directed cycle with t ≤ d distinct vertices. If that cycle has n_L > 0 loads and n_P > 0 pushes, then n_P < t ≤ d. Loads recur identically in each traversal, so the emitted word per cycle has length n_P; reversing its chronological order for the ascending-memory stack view still gives an output of period n_P. If this infinite output equals a shift of the input, n_P must be a positive multiple of the primitive period d, contradicting 0 < n_P < d. An all-load cycle produces no unbounded output. An all-push cycle visits every residue and emits a constant, matching only the excluded constant opcode word with its specially initialized register. Finite transients cannot alter the recurrent contradiction. Multiple opcode identities do not change the boundary argument. ∎

The proof is not a theorem about every finite 6502 encounter, every instruction family or all nonperiodic streams. In particular it neither proves a Toeplitz structure for arbitrary mixtures nor proves that all 6502 replicators are confined. The symbolic minimal-cycle search records 992 width-one count cases through execution period 64, all unsatisfiable without unknowns. The independent union-find enumeration directly checked 165,580,120 token orders through period 40. These searches check the restricted theorem; the 17,167,680,177,532 unreduced orders covered by the reduction were not enumerated individually. [Generated records: `results/literal_channel/minimal_symbolic_search.csv`, `results/literal_channel/direct_search.csv`, `results/literal_channel/direct_run.json`, `results/literal_channel/verification.csv`]

For every w ≥ 2, mixtures provide a different construction: with identity byte layout, the input (a b^(w−1))^∞ executes a load of b^(w−1)a followed by w−1 pushes. Its execution cycle consumes 2w bytes, and every output block is a shift of the same period-w word. At w = 3 this is input `(a b b)^∞`, decoded `a [b b a]; b; b`, which emits repeated `b b a`. It refutes an odd-width prohibition for arbitrary mixtures while respecting the repeated-pair theorem’s narrower scope. [Constructions: `results/literal_channel/minimal_witnesses.json`, `results/literal_channel/direct_witnesses.json`]

A finite width-one factor witness further separates infinite equality from bootstrap. The 16-byte input `a9 a9 a9 48 48 a9 a9 48 48 48 a9 a9 a9 48 48 48` decodes `LLPLPPPLLPP`. Its five loads and six pushes produce a matching 16-byte factor at a cyclic shift, but disagree at byte 17; the input primitive period is 16 and output period six. The Fine–Wilf threshold for those periods is 16+6−gcd(16,6) = 20. In the actual zero-partner 6502 ring this tape fails at budgets 39, 128 and 512 under both BRK rules: the presumed unmodified infinite tiling does not bootstrap when the pointer reaches virgin partner bytes. All six replays are retained. [Generated witness and replays: `results/literal_channel/finite_witness.json`, `results/literal_channel/finite_search.csv`, `results/literal_channel/6502_finite_harness.json`]
