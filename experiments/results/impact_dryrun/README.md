These are decisive attribution counts. `attribution.csv` and `attribution_totals.csv` also count every census event; `dryrun_affected_pairs.csv` records each affected pair and the first and decisive events. Any “other” stops the job; none occurred.

The Metal/Vulkan cross-platform check was byte-identical across 856,976 bytes (records, memories, state, write counts and canonical attribution for the same sampled condition), in 0.73 s locally and 7.05 s remotely. See `cross_local.json`, `cross_remote.json` and `metrics.csv`.

The detached job took 34.13 min, including supplemental C0 proofs, dry-run chunks, benchmarks and volume commits. Every chunk was committed to `algocell-atlas-runs`; `modal_call.json` identifies the call and volume path. The estimate was $2.50; measured-runtime compute cost is $1.204, against a $4.57 compute allowance. The model uses CLI allocation rates and excludes container startup/idle and storage. The CLI billing report attributes $1.212 to these impact apps (`billing.json`). See `metrics.csv`.

For the full proposed scope, 78,700,000 pairs project to 1.29 h / $2.72, or 2.87 h / $6.05 with per-condition affected-union upper bounds. `projection.csv` separates draft and added scopes; `projection_conditions.csv` gives the inputs and components. This planning model scales preparation conservatively, interpolates measured throughput by length within each rule, scales unmeasured budgets linearly, and charges one measured census batch per expected affected batch. Census benchmarks use uniform random pairs, so affected-archive batch cost remains a proxy. Extra sparse-lane reset dispatches use the dry batch execution time as a generous latency proxy; the upper scenario assumes a separate reset for every selected lane. It excludes assays and upload time; the upper scenario is not a simultaneous time confidence bound.

The worker's benchmark total-wall timer had a variable collision, fixed after execution. `bench_raw.csv` preserves that output; `bench.csv` omits the invalid column and reports the independently measured execution and census phases. Those valid phase timings drive the projection. Condition and whole-job wall timers were unaffected.

Exclusion uses dry stream 210 and registered stream 1. Each registered condition's 100,000 draws were regenerated without execution. Colliding dry draws were redrawn. `exclusion.csv` proves 0 overlapping draws across 787 conditions and verifies the transported and executed draw/pair digests against the archive. Random exclusion compares pair bytes; archived exclusion compares (source, cell, partner) slots. Clonal byte pairs in different slots can coincide; exclusion is of sampled encounters.

**C0 proof scope:** `proof_summary.csv` combines the original and supplemental checks: 92 worlds, 6,060,000 pairs, 0 mismatches and 120 negative controls caught. These compare against `z80_test_*` single-pair executors, not the `sim_*` shaders that generated the soups. The separate [ZSoup lockstep proof](../zsoup/lockstep.md) covers the `sim_*` side for plain and lethal L16/L32 worlds. Dial, randreg and randsp use the executor's random stream, seeded by case index, rather than the soup encounter stream; their proof is not encounter-stream or soup-trajectory equivalence.

See [PROTOCOL.md](PROTOCOL.md) for ambiguities and proposed registration fixes. The ring sweep is explicitly exploratory evidence for Extended Data Fig. 3; its final and emergence archives enter the added tier. R2 final soups retain their original suppression masks.
