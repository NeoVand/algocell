## The rule and where it lives

`zero_halts`: when the Z80 core fetches an opcode byte equal to 0x00 (NOP) at the start of an instruction, the pair's execution halts
for the rest of the encounter — the remaining budget is forfeited and the two memories are written back as they are (as an unmatched
bracket halts a BFF program). It is implemented as one statement inserted into `z80_step()` right after the opcode fetch
(`var op = z80_fetch(); r_inc();`), i.e. BEFORE the DD/FD prefix resolution and BEFORE the suppression hook `on_fetch_opcode`:

```wgsl
if (op == 0u) { cpu_halted = 1u; cpu_pc = (cpu_pc - 1u) & 0xffffu; return; }
```

The instruction loops of both entry points already stop on `cpu_halted` (the HALT instruction uses the same flag), so the pair
forfeits its budget and `store_pair_mem` writes the memories back unchanged from that point. Because the check sits on the first
fetch only, it never fires on prefixed opcodes (`DD 00`, `FD 00`, `ED 00`, `CB 00`) nor on operand bytes. The derived shaders
`algocell_exp/shader/sim_lethal_L16.wgsl` (from `sim_square_L16.wgsl`) and `algocell_exp/shader/z80_test_lethal_L16.wgsl` (from
`z80_test_L16.wgsl`) are produced by `algocell_exp/gen_lethal_shader.py` and are byte-identical to their sources apart from that
hunk (asserted by the generator and by `tests/test_lethal.py`). `Soup(zero_halts=True)` selects the simulation shader (square grid
only); `assay`, `assay_many`, `execute_pairs` and `closure.partner_test` take `zero_halts` and select the lethal executor, so the
culture tests, the partner tests and the c4 census of a Stage I world run under the world's own rule (`assay_batch.py`,
`c4_functional.py` and `stage_g.py` read the flag from each run's summary / `assays.csv`; the columns `zero_halts` and `executor`
record it per row, and every GPU assay script logs `executor z80_test_lethal_L16.wgsl (zero_halts)`).

## 0. Before the launch (local GPU only; no paid compute)

```sh
.venv/bin/python -m algocell_exp.gen_lethal_shader --check    # both derived shaders equal the square shader / executor + the one-statement hunk
.venv/bin/python -m pytest tests -q                            # 77 tests, incl. tests/test_lethal.py (exact bytes, identity when no zero is fetched, smoke run, condition file)
.venv/bin/python make_conds.py stageI                          # only if make_conds.py changed; conds/stageI.json must equal the generator (tested)
.venv/bin/python preflight.py conds/stageI.json --skip-tests --no-volume-check   # optional: condition-file checks (shaders present, label resolves); runs 1 representative locally
```

The dry run that preceded the launch (one world, horizon 1,000, `runs/stageI_dry/`, log `runs/stageI_dry.log`):

```sh
.venv/bin/python stage_h_local.py --stage I --only 1 --horizon 1000 --out runs/stageI_dry
```

`stage_h_local.py --stage I` refuses a `--horizon` override into `runs/stageI` (and into `runs/stageH`), so truncated runs can never
sit next to the real files.

## 1. The runs (sequential on the local GPU; resumable)

```sh
.venv/bin/python stage_h_local.py --stage I > runs/stageI_launch.log 2>&1
```

Produces, per world, `runs/stageI/lethal@closure_L16_st128_k4_s40NN.jsonl` (condition record with `zero_halts: true`, 698 samples,
summary line), `.summary.json` (written last, atomically; records `zero_halts: true`, `grid: "square"`,
`provenance.shader_file = sim_lethal_L16.wgsl`, `provenance.stage = "I"`, `purpose = "lethal-tar control (zero_halts)"`, git commit,
condition-file hash, launch time), `.soup_emergence.u8.br` (first tq_10 crossing, if any), `.soup_final.u8.br`, and
`.soup_t{500,1000,2000,3000,5000,7500,10000,15000,20000,30000,50000,75000,100000,150000,200000,300000}.u8.br` with an interaction
census in the sample of each snapshot step. `batch.check_outputs` runs on every world (schedule, snapshots, census, parameter echo
incl. grid and `zero_halts`); problems are printed and make the exit status non-zero. A world whose summary exists is skipped, so
after an interruption re-run the same command. Measured on the Apple M4 (dry run, while the Stage H sweep shared the GPU): 1.34 ms
per step on the GPU plus sampling → ≈ 7.5 min per world at the dry run's 50-step sampling rate, ≈ 1.2 h for all ten as an upper
bound (Stage H worlds took ≈ 2.5 min each at the real 500-step cadence; halted pairs make the lethal soup no slower).

## 6. Stage I scoring (I1–I4 against Stage G L = 16) — NOT YET WRITTEN

Inputs are complete after steps 2–4. Per PLAN.md: **I1** zero fraction ≥ 0.15 at step 500 in ≥ 7/10 worlds (`jsonl` sample at step 500,
`zero_frac`; also `c4/functional.csv`); **I2** among worlds with a heritable replicator (`assays.csv`: `t_rep`, `trep_tape`), population
heritability (`c4/functional.csv`: `frac_heritable`) stays < 0.3 and the first replicator's class share falls below 1% within 100,000
steps of t_rep (`jsonl` samples: `top3_shares` / exemplars), or the world closes — "open, then extinct" in ≥ 5/10; **I3** worlds with a
closed dominant (`stage_g_runs.csv`: `final_has_cf` and `frac_heritable ≥ 0.7`) by 300,000 ≤ 6/10 (control 20/20; kill: ≥ 9/10);
**I4** (descriptive) any closed dominant contains no zero byte and its pointer never enters the partner (`trace_z80.py` pattern on the
lethal executor); strong form: ≥ 7/10 worlds never produce a heritable replicator. Baselines from `results/stageG/c4/functional.csv`
and `results/stageG/stageG/stage_g_runs.csv` (tape_len 16): t_rep median 525, pusher first 20/20, t_close70 median 30,000 (20/20).
scipy is not installed: any test statistic must be computed in the script (as `stage_h_analysis.py` does).
